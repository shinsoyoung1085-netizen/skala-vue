# 날씨 Mockup — Vue 3 실습 과제

`index.html` 하나로 동작하는 Vue 3(CDN) 기반 날씨 카드 대시보드입니다. 브라우저에서 `index.html`을 열면 바로 실행됩니다.

## 요구사항 대비 구현 위치

| 요구사항 | 구현 |
|---|---|
| 배열 렌더링 (`v-for`, `:key`) | `weatherList`를 카드로 반복 렌더링, `:key="city.id"` |
| 조건부 렌더링 (`v-if`/`v-else`) | 기온 25도 기준 "🔥더움" / "❄️선선함" 라벨 분기 |
| 양방향 바인딩 & 한글 처리 (`:value`, `@input`) | 검색창 입력값을 `searchText`에 반영, 입력한 도시명 출력 |
| 이벤트 및 수식어 | 카드 클릭 시 상태바 메시지 표시, [상세보기] 버튼은 `@click.stop`으로 버블링 차단 후 `window.alert` |

## 추가로 실습한 부분

- `computed()`를 이용해 검색어로 카드 목록 자체를 필터링
- 날씨 상태(맑음/비/구름)에 따른 아이콘 매핑
- 카드에 `tabindex` + `@keydown.enter`로 키보드 접근성 지원
- `v-cloak`으로 초기 렌더링 시 `{{ }}` 원문 노출 방지
